目录迁移时，要核对新旧访问权限是否完全等价。请为虚构目录树编写这项审计。旧策略在路径节点声明允许和禁止项，项可仅作用自身或继续向下继承，匹配用户由稳定用户 ID 或静态组（组可嵌套，禁止环）确定。对每个已登记用户、目录和操作，取匹配的最深节点，节点内禁止优先，否则取允许；无匹配时默认禁止。目标系统只接受显式用户组、单种操作和节点或子树的正向授权，没有拒绝项。输入提供可用的有限授权条目候选，每条成本非负，发布后的权限取所选条目并集；系统自带一组不能移除的授权。
synthesize 找出权限矩阵完全等价的最低成本清单，依次按成本、条目数、升序 ID 破平。任何覆盖禁止单元的候选不能选；固定授权超权时立即解释最小 (路径,用户,操作) 反例；有允许单元没有安全候选覆盖时解释未覆盖反例与每个可能覆盖它的候选所带最小越权单元。verify 给方案逐项算旧新差异及来源。支持数百目录、数千对象以及至多 32 个候选授权项，使用覆盖和支配剪枝。测试覆盖祖先拒绝被子节点允许覆盖、继承组菱形、ACL 朴素复制扩大权限、两个低成本授权合成优于大授权、无解和行序无关。

加入多版本迁移窗口。多个部门在相邻时段复用同一目标权限服务。每一时段输入声明适用的旧 ACL 版本、固定基础授权和必须活跃的用户范围；ACL 发生变化可以使同一候选项在一段必需、在另一段越权。允许每段选择快照中的一个授权集，候选可设置跨段最短保持期、启动费用及保持每段费用。以每段都完全等价为硬约束，同时限制任意相邻段之间能够变更的条目数；选择不得在边界出现短暂额外授权。目标改为最小化全窗口的启动和保持费用，其次最少变更次数，最后按段起点和升序 ID 列表决胜。plan 还输出给原子切换所需的预期旧新版本。apply 将快照版本绑定到 SQLite 的 compare-and-set，带幂等回执；源 ACL 在计划后变化则原子拒绝。用小树对拍，覆盖每段能单独合成却不能连续迁移、费用低清单需要提前启用却临时越权、固定授权比其他候选更早触发超权，以及阶段费用破平和回执后重试。

请提供可直接跑的权限迁移样例，样例和夹具数据均在本地虚构生成。调用入口是 `python -m solution <命令> CASE.json`，需要保留状态时传入 `--db DB.sqlite`。stdout 应提供 UTF-8 编码的 JSON，重复同一逻辑案例应取得一致结果，结构错误要指出错误码和字段位置。项目从空仓库实现，限定 Windows 原生 Python 3.12、标准库和 CPU。README 写明完整的输入输出定义及如何复现，`python -m unittest discover -s tests -v` 能运行全部断言测试。
